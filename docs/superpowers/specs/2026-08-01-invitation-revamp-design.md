# 모바일 청첩장 리뉴얼 설계

## 배경

현재 청첩장은 표지·인사말·예식정보·갤러리·연락처·계좌 6개 섹션으로 동작 중이며, 데이터(`js/data.js`)와 렌더 로직(`js/main.js`)이 분리되어 있음. 브레인스토밍을 통해 다음 세 축으로 보완하기로 함: 콘텐츠 보강, 디자인 톤 전환, 인터랙션 기능 추가.

## 1. 콘텐츠 변경

- **인사말 섹션**에 부모님 성함 표기 추가. 표지는 신랑신부 이름만 유지.
  - 형식: `OOO · OOO 의 장남 김재원` / `OOO · OOO 의 차녀 이예지` 형태
  - 부모님 실제 성함은 사용자가 추후 제공. 확인 전까지 `data.js`에 빈 값/플레이스홀더 필드만 만들어 두고 임의 값은 넣지 않음.
- **RSVP 섹션 신설**: 성함 / 참석 여부 / 참석 인원 / 식사 여부(선택) 입력 폼
- **방명록 섹션 신설**: 이름 + 축하 메시지 입력, 제출 후 최신순으로 목록 표시

## 2. 디자인 리뉴얼 (귀여운 톤 → 오멘/고급스러운 톤)

- **폰트**: `Jua`, `Gaegu` 제거 → 한글은 세리프 계열(`Noto Serif KR` 또는 `Song Myung`), 영문 포인트(이름·날짜)는 얇은 세리프(`Cormorant Garamond`)
- **컬러**: 파스텔 제거 → 아이보리/오프화이트 배경 + 차콜 텍스트, 포인트 컬러 1개(딥그린 계열)만 소량 사용
- **장식 요소**: 하트/이모지 floating background(`renderFloatingBackground`) 완전 제거. 섹션 라벨의 이모지(✨💌📍📸💕🎁)도 제거하고 영문 대문자 라벨 + 얇은 라인 구분자로 교체
- **레이아웃**: 여백 확대, 얇은 divider로 섹션 구분. 카드형 구조 자체는 유지
- **애니메이션**: 기존 스크롤 fade-in(`setupScrollReveal`)만 유지, 신규 효과 추가 없음

## 3. 기능 아키텍처

### 3.1 백엔드: Google Apps Script Web App

- 정적 사이트 제약을 유지하기 위해 Google Apps Script를 경량 백엔드로 사용
- Google Sheet에 탭 2개: `RSVP응답`, `방명록`
- 스크립트는 `doPost(e)` 하나로 요청을 받아 `body.type`(`"rsvp"` | `"guestbook"`)에 따라 해당 탭에 행 추가
- 방명록 목록 조회는 별도 `doGet(e)`으로 최근 N개 메시지를 JSON으로 반환
- **배포는 사용자가 직접 진행** (Google 계정 로그인 필요). 스크립트 코드는 제공하되, 생성·배포·URL 발급은 단계별로 안내하며 사용자가 수행

### 3.2 프론트엔드 연동

- `js/data.js`에 필드 추가: `appsScriptUrl` (기본값 빈 문자열)
- `js/main.js`에 RSVP/방명록 렌더 + 제출 함수 추가
  - `appsScriptUrl`이 비어있으면 폼 제출 시 안내 토스트만 띄우고 실패하지 않도록 방어 처리 (배포 전에도 페이지가 깨지지 않아야 함)
  - 제출 성공 시 방명록은 목록 재조회 후 갱신
- 에러 처리: 네트워크 실패 시 토스트로 실패 안내, 콘솔 에러 로그는 남기되 사용자에게는 재시도 유도 메시지만 노출

### 3.3 공유하기

- **링크 복사**: 기존 계좌번호 복사(`copyToClipboard`)와 동일 패턴으로 즉시 구현, 별도 설정 불필요
- **카카오톡 공유**: `js/data.js`에 `kakaoJsKey` 필드 추가 (기본값 빈 문자열)
  - 키가 비어있으면 카카오 공유 버튼 자체를 렌더링하지 않음 (에러 없이 안전하게 동작)
  - 키 발급은 Kakao Developers 콘솔에서 사용자가 직접 진행, 단계별 안내 제공 후 값 채움

## 4. 제외 항목

- **배경음악**: 음원 파일 미확보로 이번 스코프에서 제외. 추후 파일 확보 시 별도 작업으로 진행
- **부모님 성함 실제 값**: 확인 전까지 UI 구조만 준비, 실제 텍스트는 사용자 확인 후 반영

## 5. 작업 순서 제안 (구현 단계에서 세분화 예정)

1. 디자인 시스템 교체 (폰트/컬러/장식 제거) — 기존 콘텐츠 구조는 유지한 채 톤만 전환
2. 인사말 섹션에 부모님 성함 필드 추가 (빈 값 허용)
3. RSVP 섹션 + 프론트 로직 (Apps Script 미배포 상태에서도 안전하게 동작)
4. 방명록 섹션 + 프론트 로직
5. 공유하기(링크 복사 즉시 / 카카오 버튼은 키 유무에 따라 조건부 렌더)
6. Google Apps Script 코드 작성 → 사용자가 단계별로 배포 진행 → `appsScriptUrl` 값 반영
7. Kakao Developers 앱 생성 → 사용자가 단계별로 진행 → `kakaoJsKey` 값 반영

## 테스트 방식

- 기존 `test/validate.mjs`에 신규 필드(`appsScriptUrl`, `kakaoJsKey`, 부모님 성함 필드) 존재 여부 검증 추가
- 로컬 서버(`http://172.30.1.56:8080`)로 실기기(폰)에서 직접 확인하며 진행 (사용자 확인 방식 유지)
